# Baker — Mac setup

One command sets up a new Mac for Baker (tools, sign-ins, Conductor):

```bash
curl -fsSL https://raw.githubusercontent.com/koda-sl/baker-setup/main/onboard.sh | bash
```

Safe to re-run any time — finished steps are skipped.

> Source of truth: `scripts/dev/onboard.sh` in the private `koda-sl/baker` repo.
> To update this copy: `cp scripts/dev/onboard.sh` here and push.
